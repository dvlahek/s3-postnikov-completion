# s3-postnikov-completion

Numerical code accompanying the manuscript **Postnikov completion of the topological sector of a four-dimensional lattice sigma model with three-sphere target**.

The repository contains the four parts of the numerical and finite validation used in the paper:

- `cochain_checks.py` evaluates the simplicial cup-i formulas, the ordered five-simplex Sq^2 relation, and the descendant identity.
- `pi4_preimage_framing.py` evaluates the regular-value preimage and differential-induced framing of the suspended-Hopf representative.
- `topology_benchmarks.py` runs the smooth skyrmion, gerbe/Stokes, and lattice pi4 benchmarks.
- the equilibrium scripts run and analyse the four-dimensional O(4) / S3 model with the production measurement schedule used in the paper.

## Installation

Python 3.10 or newer is recommended.

```bash
python -m venv .venv
```

Windows:

```text
.venv\Scripts\activate
pip install -r requirements.txt
RUN_ALL.bat
```

Linux/macOS:

```bash
source .venv/bin/activate
pip install -r requirements.txt
./run_all.sh
```

A shorter code-path check is available through `RUN_QUICK.bat` or `./run_quick.sh`. The short chains used by that profile are not intended for the statistical results in the paper.

## Production Monte Carlo protocol

The production measurement time never depends on a realised cluster size. Two discarded pilot chains are used to estimate a fixed number of Wolff steps for every `(L, beta)` ensemble. Production then uses:

- an adaptive burn-in to 200 lattice-volume cluster equivalents; this stage is discarded;
- 20 fixed-count washout intervals after burn-in;
- a fixed number of Wolff steps between every recorded configuration;
- four independent chains per ensemble, two cold and two hot;
- 800 recorded configurations per chain.

The final grid contains 124 chains in 31 ensembles, with lattice sizes up to `L=16`. The same analysis script computes split-Rhat, autocorrelation times, effective sample sizes, hot/cold diagnostics, circular moving-block bootstrap intervals, and the finite-size crossing figures.

## Independent sampler check

`sampler_crosscheck.py` compares the production Wolff sampler with an exact single-site O(4) heat bath and a checkerboard Metropolis sampler at `L=4`. The repository also keeps a state-dependent measurement-time rule as a negative control. The reference output shows agreement between the stationary samplers and a clear shift for the negative control.

## Reference outputs

The `reference/` directory contains compact numerical outputs from the campaign used in the manuscript. Raw Markov-chain trajectories are not stored in Git because they are regenerated by the production scripts from fixed seeds.

The largest-volume crossings of `xi/L` are close to `beta = 0.6080` under the action normalization used in the paper. The corresponding Binder-ratio crossings are close to `0.6085`. These values are reported only as a finite-size dynamical consistency check. The repository does not use them as a precision infinite-volume critical-coupling estimate.

## Reproducibility

Run the complete calculation with:

```bash
python run_all.py --profile paper --fresh
```

The compact reference values used in the manuscript are summarized in `RESULTS_REFERENCE.md`.
